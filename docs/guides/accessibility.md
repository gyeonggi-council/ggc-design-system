# 접근성 — 값과 무관하게 지키는 것

경기도의회는 공공기관이라 **KWCAG 2.2 / WCAG AA(4.5:1)** 가 법적 준수 대상이다. 토큰 v1.2 이후 정본 자체는 AA 를 통과한다
(`design/examples/tokens.html` 이 대비비를 실측해 보여 준다). 아래는 **값을 바꾸지 않아도** 서비스가 지켜야 하는 것이다.

## 다섯 가지

1. **색 단독으로 의미를 전달하지 않는다.** 배지·알림·상태에는 텍스트나 기호(✓ ◷ ✕ ● ◆ ○ ⚠)를 함께 둔다. 색각 이상 사용자에게는 대비만으로 부족하다.
2. **`--ggc-text-faint` 를 글자에 쓰지 않는다.** 흰 위 3.07:1 — 아이콘·구분·장식 전용이다.
3. **링크에 밑줄.** 본문 안 링크는 밑줄이 있어야 색각과 무관하게 링크로 읽힌다.
4. **`:focus-visible` 링을 없애지 않는다.** 디자인 원본의 `outline:none` 28건을 복제하지 않는다. 토큰이 전역 링을 제공한다.
5. **placeholder 를 유일한 라벨로 쓰지 않는다.** 입력을 시작하면 사라진다. 라벨을 숨겨야 하면 `.ggc-sr`.

## 키보드

- `Tab` 순서가 화면 순서와 같다. 스킵 링크(`.ggc-skip-link`)가 첫 Tab 이다.
- 탭은 roving tabindex(선택 탭 하나만 Tab 정지, 화살표로 이동). 모달은 포커스를 가두고 닫히면 열었던 곳으로 돌아온다.
- 드롭다운·메뉴는 `Esc` 로 닫힌다. 파괴적 동작은 확인 단계가 있다.
- 커스텀 컨트롤(체크·라디오·칩)은 네이티브 input 을 숨겼을 뿐이라 Space·화살표가 그대로 동작한다.

## 고대비 — 팔레트를 하나 더 만들지 않는다

- **Windows 고대비(`forced-colors: active`)**: OS 가 색을 갈아끼운다. `box-shadow` 가 렌더되지 않아 포커스 링이 사라지므로 토큰이 `outline` 으로 복원하고,
  배경만으로 구분되던 것(배지 · 활성 내비 · 합계행 · 현재 단계 · 체크 상태)에 테두리·outline 을 보장한다. 새 컴포넌트를 만들면 같은 보장을 한다.
- **`prefers-contrast: more`**: 색 반전 없이 중립 텍스트를 한 단계 진하게, 링을 두껍게. 같은 토큰 이름의 미디어 오버라이드라 서비스가 할 일이 없다.
- KRDS 의 `mode-high-contrast` 는 밝은 글자를 쓰는 사실상 다크 테마다 — 따르지 않는다(계약 §3-2). 다크모드는 비범위다.

## 모션 · 인쇄

- `prefers-reduced-motion: reduce` 에서 정본이 애니메이션·전환을 전역으로 끈다. 스피너·스켈레톤·모달 전환이 포함된다.
- 공문·명단·안내문은 출력된다. 대민 셸은 `@media print` 에서 셸을 걷어낸다. 업무 화면도 출력 대상이면 같은 처리를 한다.

## 검사

`check_design.py` D5 가 `:focus-visible` 부재·대체 없는 `outline:none`·(enforce 모드) 4.5:1 미달을 잡는다. 대민 페이지는
스킬 검증 스크립트가 h1 하나 · 이미지 alt · 컨트롤 라벨 · 랜드마크 · 스킵 링크 대상 · 버튼 이름 · id 중복을 추가로 본다.
**16px 탭에서의 파비콘 · Tab 순회의 실제 느낌 · 390px 실물 · iOS 홈 화면**은 자동화되지 않는다 — 사람이 본다.
