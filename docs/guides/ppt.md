# PPT 가이드 — 대외 발표 · 설명회용 (v3.0)

용도: **도민 · 외부 기관 대상 발표와 설명회**(사용자 결정 2026-09-05). 내부 결재용 보고서형은 범위 밖이다.
템플릿과 샘플 덱은 **생성물**이다 — `design/ppt/build-ppt.py` 가 `design/ggc-tokens.css` 의 값을 읽어 만든다. 색을 손으로 적지 않는다.

| `design/ppt/dist/ggc-presentation-template.pptx` | 16:9 · 레이아웃 10종 자리표시 — 이것을 복사해 시작한다 |
| `design/ppt/dist/ggc-presentation-sample.pptx` | 같은 템플릿으로 만든 12장 — "의정정보시스템 소개". 어떤 자리에 무엇을 쓰는지의 실물 |
| `design/ppt/dist/manifest.json` | 입력 해시 · 레이아웃 목록. `check_design.py --canon` D6 gen 이 신선도를 본다 |

## 먼저 — 서체

**Pretendard GOV** 를 발표 PC 에 설치한다(`design/fonts/` 의 웹폰트가 아니라 데스크톱용 OTF/TTF — 공공 무료 배포).
미설치 PC 에서는 **맑은 고딕**으로 대체되며 레이아웃은 그대로다. 외부 PC 로 파일이 나갈 때는 PowerPoint 「파일 → 옵션 → 저장 → 글꼴 포함」을 켠다.

## 레이아웃 10종 — 어디에 무엇을

| # | 레이아웃 | 언제 | 규칙 |
|---|---|---|---|
| 1 | 표지 | 첫 장 | 네이비 판 + 의회 마크 + 제목(40) · 부제(20) · 일자 · 기관. 제목은 두 줄까지 |
| 2 | 목차 | 둘째 장 | 4~6 항목. 번호 배지 + 제목 한 줄 |
| 3 | 섹션 구분 | 장이 바뀔 때 | 네이비 판 + 번호(48) + 섹션 제목(36) + 부제 한 줄 |
| 4 | 본문 · 불릿 | 기본 | 제목(28) + 불릿 ≤ **6줄** · 하위 단계 하나만. 아래 강조 상자에 핵심 한 문장 |
| 5 | 본문 · 2단 | 비교(현행 · 개선) | 두 카드 같은 높이. 항목 3~4개씩 |
| 6 | 이미지 강조 | 화면 · 도해 | 16:9 캡처, 여백 없이. 캡션은 아래 한 줄 "그림 N. 설명 — 출처". 실제 데이터는 마스킹 |
| 7 | 표 | 수치 대조 | 머리글 primary-deep + 흰 글자 · 줄무늬 · 합계행 인셋. 숫자 우정렬 · 단위는 부제에 |
| 8 | 차트 | 추이 · 비교 | 색은 chart-1..5(= primary · info · success · warning · danger) 순서로만. 격자선 hairline · 범례 아래 |
| 9 | 핵심 수치 | 성과 요약 | KPI 3~4개. 숫자(44) + 단위 + 라벨 + 추이(성공/경고/오류색) |
| 10 | 마무리 | 끝 | 네이비 판 + "감사합니다" + 담당 부서 · 대표전화 · 이메일 · 누리집 |

한 덱에 **섹션 3~4 · 전체 12~20장**. 20장을 넘으면 부록으로 뺀다.

## 색 — 토큰 그대로, 주색 하나

- **주색은 네이비 하나**(`--ggc-primary` · `-deep`). 표지 · 섹션 · 마무리의 판, 제목 띠, 표 머리글, 차트 첫 계열에만.
- **상태색(성공 · 경고 · 오류 · 정보)은 데이터에만** — KPI 추이, 차트 계열, 강조 상자 띠. 장식으로 쓰지 않는다.
- **중립 램프**(`--ggc-text-strong` · `text` · `text-muted` · `text-subtle`)로 위계를 만든다. 검정(#000)을 쓰지 않는다.
- 배경은 흰색(`--ggc-surface`). 회색 판은 `--ggc-surface-inset` · `--ggc-bg` 둘뿐.
- 그라데이션 · 그림자 · 3D 효과 · 클립아트 금지. 아이콘이 필요하면 lucide(`design/icons/lucide/`)를 24px 이상 단색으로.

## 글

- 제목 28 · 본문 18/16 · 캡션 12 · 표 13. **한 장에 글자 크기 3단계까지.**
- 굵기는 400 · 700 둘. 밑줄 · 기울임 · 그림자 텍스트 금지. 강조는 굵기와 색(`--ggc-primary`)으로.
- 한 장에 메시지 하나. 제목이 곧 결론("접수 의안 12% 증가") — "현황" 같은 명사만 두지 않는다.

## 어휘 — 대민 (domain-language.md 대민 절)

- **존댓말(–합니다)** 전면. 업무 어휘(회부 · 상신)는 쓰되 **풀이 한 줄**을 붙인다("회부 — 위원회에 심사를 맡기는 것").
- 법령 · 조례는 「낫표」 + 공포 명칭 그대로. 날짜 `YYYY-MM-DD` 또는 `2026. 9. 5.` 하나로 통일. 상대시간 금지.
- 숫자는 단위와 함께("184,200명"). 천단위 콤마.
- "혁신적인" · "손쉽게" 류 자랑 형용사 0건. 이모지 0건.
- 사람: 의원은 `○○○ 의원`, 직원 실명은 담당 연락처에만. 개인정보 · 실제 의안의 민감 정보는 예시 데이터로 대체.
- 마무리 장에 **담당 부서 + 대표전화**를 반드시 — 없는 설명회 자료는 완성이 아니다.

## Do / Don't

| Do | Don't |
|---|---|
| 템플릿의 레이아웃 10종 안에서만 조립 | 새 레이아웃 · 새 색 만들기(필요하면 `build-ppt.py` 에 넣고 다시 생성) |
| 차트는 PowerPoint 네이티브 차트(색은 템플릿이 준다) | 다른 도구 캡처 차트 붙이기 |
| 화면 캡처는 갤러리 · 실제 화면을 16:9 로 | 브라우저 크롬 · 마우스 커서 · 실명 노출 |
| 푸터의 기관명 · 쪽번호 유지 | 푸터 지우기 · 로고 변형 · 마크 위에 글자 얹기 |
| 발표자 노트에 출처 · 근거 기록 | 슬라이드에 출처 없이 수치 넣기 |

## 다시 만들기

```bash
pip install python-pptx            # 생성에만 필요. --check 는 표준 라이브러리
python design/ppt/build-ppt.py     # 토큰이 바뀌면 다시 — 색이 자동으로 따라온다
python design/ppt/build-ppt.py --check
```

레이아웃을 바꾸려면 `build-ppt.py` 의 `l_*` 함수를 고친다 — 값(hex)은 함수에 없고 `tokens()` 에서 온다.
LibreOffice 가 있으면 `soffice --headless --convert-to pdf dist/*.pptx` 로 미리보기 PDF 를 만들 수 있다(저장소에는 넣지 않는다).
