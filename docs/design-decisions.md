프로필: work (주요 업무 화면), public (기존 대민 화면 회귀 검사)

정본 루트: 이 문서의 상위 저장소. Tier 1 정본 CSS·JS를 직접 개선한다.
Phase 0: `python design/check_design.py --report design/examples`는 인라인형, D1~D5 PASS였다.
그러나 실제 브라우저에서 모바일 의안 목록의 가로 넘침과 메뉴 누락을 확인했다.

셸: 기존 기관 브랜드·헤더·사이드바를 유지하며 공통 메뉴 동작을 보강한다.
패턴: 대시보드 Monitor, 목록 Explore, 초안 Configure. `.ggc-work`로 밀도를 선택적으로 높인다.
접근성: 기존 AA 토큰과 포커스 링 유지. 메뉴 포커스 순환·복귀와 닫힌 메뉴의 `inert`를 추가한다.
확폭: 기존 확폭 규칙 유지. 320/390/768/1024/1440/1920에서 검사한다.
예외: 새 브랜드색·토큰 값 예외 없음. 갤러리 폰트 경로는 정본 선언에서 생성한다.

어휘·밀도: 의안번호·위원회·제안자·접수일·경과·상태를 유지한다.
PC 목록은 처음부터 15행, 모바일은 전체 상세가 있는 카드 5건과 페이지 이동을 기본으로 제공한다.
인증되지 않은 오프라인 예제에서는 가상의 '내 소관'을 적용하지 않고 전체 예시 의안을 기본으로 한다.
접힌 필터에는 적용 조건 수를 표시한다. 개발자용 설명은 가이드로 접어 업무 영역을 확보한다.
실제 제출·회부를 수행한 것처럼 표시하지 않는다. 임시저장은 현재 기기에만 저장한다.
