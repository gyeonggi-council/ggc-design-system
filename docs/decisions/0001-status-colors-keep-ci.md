# 0001 — 상태색을 KRDS 로 수렴하지 않는다 (2026-08-22)

## 상황
토큰 v1.1 의 상태색 4종이 자기 틴트 위에서 3.65~3.83:1 로 AA 미달이었다. KRDS 값(danger `#BD2C0F` 등)을 채택하면 대비가 0.5~0.7 좋아진다.

## 결정
KRDS 값을 쓰지 않고, **디자인 원본의 색상각을 유지한 채 명도만 낮춰 AA 를 넘긴 값**을 v1.2 로 채택한다
(success `#0A7B4E` · warning `#9D5E00` · danger `#CD2D2D` · info `#1F6A97`).

## 근거
CIELAB ΔE 로 대조하니 v1.2 가 AA 통과 집합 중 원본에 가장 가깝다(ΔE 5.7~10.1, 색상각 Δ0~2°). KRDS 값은 경기도의회 CI 톤에서 멀어진다.
**기관 CI 유지가 우선**이다. KRDS 자체가 기관 CI 적용을 전제하므로 이탈이 아니다. 정부 표준 완전 준수를 주장하지 않는다.

## 결과
`docs/krds-alignment.md §2` 에 실측표. 대민 프로필(0003)에서도 상태색은 불변이다.
