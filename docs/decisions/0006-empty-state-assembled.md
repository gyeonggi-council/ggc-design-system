# 0006 — 빈 상태는 조립한다 (2026-08-29)

## 상황
빈 상태 · 오류 · 로딩 3종은 PoC 에서 가장 자주 빠지고 시연 당일에 드러난다. 갤러리는 "전용 클래스를 두지 않는 것은 의도" 라고 명시했다 —
화면마다 문구와 다음 행동이 달라서 클래스로 굳히면 누군가 자기 것을 새로 만든다.

## 결정
- **로딩**은 클래스로 고정한다 — `.ggc-skeleton` · `.ggc-spinner`(v2.0). 형태가 화면과 무관하게 같다.
- **오류**는 `.ggc-alert--danger` + 다시 시도 버튼으로 조립한다.
- **빈 상태**는 조립을 유지한다(카드 + 기호 + 제목 + 문구 + 다음 행동). 레이아웃만 고정하는 `.ggc-empty` 를 Phase 9 에 추가하되
  문구·행동은 슬롯이다. "데이터가 없습니다" 가 아니라 "접수된 건이 없습니다. 추천서 등록으로 시작합니다" 처럼 **다음 행동을 말한다.**

## 근거
로딩은 내용이 없어 고정해도 갈라질 것이 없다. 빈 상태는 내용이 본질이라 클래스가 문구까지 굳히면 화면마다 틀린 말을 하게 된다.
