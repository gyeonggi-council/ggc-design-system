# 0016 — Astryx 식 모양·깊이·중립색 · 주 강조는 잉크 · 새 부품 셋 (2026-11-07)

0015(사람과 에이전트가 같은 시스템)가 저장소의 **설명 방식**을 바꿨다면, 이 결정은 **화면의 모양**을 바꾼다 — 정본 토큰 · 컴포넌트 · 대민 셸 · Tier 2 의 값과 규칙. 글자 크기 · 밀도 · 간격 · 셸 치수 · 상태색은 바뀌지 않았다. ⚠ D1 — 전 서비스 재복사.

## 상황

0015 를 보고 사용자(11-07): "디자인이 변경되거나 그런 거는 아냐?" → "디자인 자체도 바꾸고 싶어". 질문 셋에 대한 답:
범위 = **모양·깊이·중립색 + 주색 체계까지 + 부품·패턴 추가** · 적용 = **정본에 바로 반영** · 글자 크기·밀도 = **지금 그대로**.
다크 모드는 고르지 않았다(ADR 0002 유지).

Astryx(neutral 테마)의 시각 언어를 소스에서 읽었다(렌더 화면은 망에서 열리지 않아 보지 못했다):
회색 중심 — 주 강조가 색이 아니라 거의 검은 잉크(neutral light[10]) · 유일한 유채색은 파랑(정보 · 상태 링) · 모서리 inner 6 · element 10 · container 12 · page 28 ·
그림자 low/med/high(「깊이는 조용히」 — 선과 그림자를 둘 다 세게 쓰지 않는다) · 테두리 8% 알파 · 중립 램프는 OKLCH 21 스텝 · Figtree 14px · 다크 모드 내장.

이 저장소와 부딪치는 셋: ① 주색 — 의회 남색은 `ggc-design-guide` 가 정본(0007)이고 0001 은 상태색의 CI 유지를 정했다 ② 다크 모드 — 0002 가 금지 ③ 그림자 — 0013 이 「그림자는 뜨는 층만」으로 정했다.

## 선택지

1. **Astryx 룩을 그대로** — 주색을 잉크로 바꾸고(남색 폐기) 바탕을 회색(95)으로, 다크 모드까지. 0001 · 0002 · 0007 · 0013 네 결정을 뒤집고 기관 색이 화면에서 사라진다.
2. **룩은 들여오되 브랜드 자리는 남긴다** — 주 강조는 잉크, 남색은 브랜드 자리(GNB 브랜드 · 링크 · 포커스 링 · 유틸리티 바 · 역할/납부 배지 · 대민 히어로)에만. 바탕은 흰색 유지(0013), 카드는 옅은 선 + 낮은 그림자. 다크 없음. 서체는 Pretendard GOV(Figtree 는 한글이 없다).
3. 토큰 값만 바꾸고 컴포넌트는 두기 — 모서리 · 그림자만 바뀌고 "주색 체계까지"라는 요청을 만족하지 못한다.

## 결정 — 2

1. **강조 잉크 토큰 신설** `--ggc-accent` · `-hover` · `-active` · `--ggc-on-accent` · `--ggc-accent-muted` · `-strong`. 주 버튼 · 체크 · 라디오 · 스위치 · 칩 선택 · 현재 단계 · 탭 밑줄 · 현재 쪽 · 진행 막대 · 스피너 · 선택 배경(LNB · 리스트박스 · 메뉴 포커스 · 대민 현재 메뉴 · 사이드 내비) · 표 머리선 · 스킵 링크가 잉크로. 2차 버튼은 회색 채움, ghost hover 는 반투명 `--ggc-hover-tint`.
   **남색은 브랜드 자리에만**: `--ggc-primary` 계열의 값은 그대로이고 쓰임만 줄였다 — 링크 · GNB 브랜드 · 포커스 링 · 유틸리티 바 · 역할/납부 배지 · 태그 `--primary` · 대민 히어로 바탕 · 사이드 내비 머리 · 아이덴티파이어 로고. **둘 외의 주색은 만들지 않는다**(철칙은 "새 주색 금지"에서 "잉크 + 브랜드, 그 외 금지"로).
2. **중립 램프를 OKLCH 로 다시 생성** — 의회 남색의 색상각(259.8°)을 유지한 차가운 회색, 채도 ≤ 0.014, L 0~1 의 21 스텝에서 골랐다. text-strong/-text/-body/-muted/-subtle/-faint · border/-strong · shell-border · hairline · control-bg · surface-inset · row-hover 전부. AA 유지(text-subtle 흰 5.52 · 옛 바탕 4.88). 바탕 · 면은 흰색 그대로.
3. **모서리** 6/4/12 → **10/6/12** + `--ggc-radius-full`(알약 리터럴 999px 를 토큰으로). page 28 은 쓰는 자리가 없어 만들지 않았다.
4. **깊이 세 단계** `--ggc-shadow-low/-med/-high`(값은 Astryx 와 같다) — 카드·KPI 타일 low, 메뉴·토스트·대민 전체메뉴 med, 모달 high. 테두리는 한 단계 옅게(`#DDE0E5`) — 선과 그림자를 둘 다 세게 쓰지 않는다(0013 의 「그림자는 뜨는 층만」은 여기서 대체된다. 흰 바탕 · 테두리로 면을 가른다는 뜻은 유지). `--ggc-shadow` 는 low 의 별칭으로 남겨 옛 이름이 깨지지 않는다.
5. **움직임 토큰** `--ggc-motion-fast/-medium/-slow`(125/300/700ms). 새 부품부터 쓴다.
6. **부품 셋** — §45 `.ggc-segmented`(세그먼트 컨트롤 — 같은 판의 표현 바꾸기) · §46 `.ggc-avatar`(사람 · 기관 · AI) · §47 `.ggc-agent`(AI 작업 상태 7종 — Astryx `agentic-states` 를 우리 말로; AI 의정플랫폼의 기본 부품). Tier 2 는 `toggle-group` · `avatar` 가 맡고 `agent` 는 Tier 1 만.
7. **Tier 2** — `ggc-theme` 매핑에서 `--primary` · `--accent` · `--secondary` · `--sidebar-*` 가 잉크 계열을 가리킨다. 공식 소스는 그대로이고 매핑만 바뀌어 대부분의 부품이 따라온다. 선택 색을 직접 적은 블록(qr-login · stepper · shell · file-upload · side-nav · listbox · public-header · prose)은 같은 규칙으로 고쳤다. 카드에 `shadow-(--ggc-shadow-low)`.

### 들여오지 않은 것

| Astryx | 결정 | 이유 |
|---|---|---|
| 회색 바탕(95) 위 흰 면 | 흰 바탕 유지 | 0013 의 근거(상자 겹겹 · 1.13:1)가 그대로다. 사용자가 다시 고르지 않았다 |
| 다크 모드(light-dark) | 없음 | 0002. 질문에서 고르지 않았다 |
| 주색 폐기(잉크만) | 남색은 브랜드 자리 | 기관 CI 는 `ggc-design-guide` 의 결정(0007)이고, 링크 · 포커스 링 · 브랜드에서 기관 색이 보여야 한다 |
| 파랑 정보색 #0074e2 · 노랑 경고 #ffce2f | 상태색 넷 유지 | 0001. 노랑은 글자로 AA 미달 |
| Figtree · 비율 1.2 스케일 · 휴대폰 16px | Pretendard GOV · 기존 스케일 | 한글 없음 · 사용자가 「지금 그대로」 |
| 테마 8종 | 없음 | 토큰 표면을 늘리지 않는다(0003) |
