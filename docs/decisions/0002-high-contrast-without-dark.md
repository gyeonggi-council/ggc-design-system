# 0002 — 고대비는 다크 팔레트 없이 (2026-08-22)

## 상황
KRDS 는 `mode-high-contrast` 를 토큰 레벨에서 정의하는데 전부 밝은 글자다 — 사실상 다크 테마. 계약 §3 은 다크모드를 비범위로 뒀다.

## 결정
KRDS 고대비를 따르지 않는다. **실제 사용자가 켜는 것**에 대응한다 — 사내 PC 는 Windows 고대비(`forced-colors: active`)이고 OS 가 색을 통째로 갈아끼운다.
할 일은 팔레트가 아니라 **깨지지 않게 하는 것**: `box-shadow` 가 사라지므로 포커스 링을 `outline` 으로 복원하고, 배경만으로 구분되던 것에 테두리를 보장한다.
`prefers-contrast: more` 는 같은 토큰 이름의 미디어 오버라이드로 중립을 한 단계 진하게.

## 근거
다크 팔레트를 고대비라는 이름으로 우회 도입하면 토큰 표면이 2배가 되고 "두 벌이 갈라진다". 실제로 Windows 고대비에서 포커스가 사라지던 결함을 이 과정에서 찾아 고쳤다.

## 결과
`ggc-tokens.css` · `ggc-components.css` 의 `@media (forced-colors)` · `(prefers-contrast)` 블록. 새 컴포넌트는 §24 에 같은 보장을 추가한다.
