# 0003 — 프로필은 토큰 파일 하나 + 속성 (2026-08-29)

## 상황
대민(공개) 화면을 KRDS 패턴에 맞추기로 했다(사용자 결정). 업무용과 대민용의 치수가 다르다. 파일을 둘로 나눌 것인가.

## 대안
ⓐ `ggc-tokens.css` + `ggc-profile-public.css` 두 파일 — 소비자가 파일 하나 더 복사·링크, D1 대조 2회, DESIGN.md 생성기가 병합.
ⓑ 파일 하나 + `[data-ggc-profile="public"]` 블록 — 속성 하나, 서브트리 전환 가능, 업무 앱도 대민 블록 ~40줄을 싣는다(무시 가능).

## 결정
**ⓑ.** 기본(속성 없음)이 업무 프로필이라 v1.2 소비자는 아무것도 바꾸지 않아도 렌더가 같다. 프로필 블록에는 **치수만**(컨트롤 높이 · 글자 · 셀/행/카드 패딩 · 컨테이너 폭) 들어가고
색 · 포커스 · 서체 · 간격은 들어갈 수 없다 — 검사기 D6 가 허용 목록 14종으로 강제한다. 대민 값은 KRDS 토큰(1rem=10px)에서 기계적으로 옮긴다.

## 근거
값의 원천이 두 파일이 되는 순간 갈라진다(이 저장소가 이미 겪은 실패). 대민도 기관 CI 네이비라 색은 공유되고, 다른 것은 치수뿐이다.
컴포넌트 CSS 의 리터럴을 같은 값 토큰으로 치환하는 "값 불변 리팩터"(갤러리 12조합 해시 일치 실측)가 이것을 가능하게 했다.

## 결과
계약 §9. `design/examples/tokens.html#profile` 토글. 두 프로필을 한 화면에 섞지 않는다.
