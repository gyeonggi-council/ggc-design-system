# v1.2 → v2.0 마이그레이션

토큰 파일 바이트가 바뀌었으므로 **모든 사본형(❷) 서비스의 D1 이 한 번 깨진다.**
그래서 v2.0 은 토큰 변경을 이 한 릴리스에 전부 모았다 — 재복사는 한 번이면 된다.

## 무엇이 바뀌었나 (렌더는 같다)

| 구분 | 내용 | 서비스가 할 일 |
|---|---|---|
| 토큰 파일 | `design/ggc-tokens.css` v2.0 — 신설 토큰 + `[data-ggc-profile="public"]` 블록. **v1.2 이름·값은 전부 그대로** | `cp` 로 재복사 (D1) |
| 컴포넌트 파일 | `design/ggc-components.css` v2.0 — 리터럴 → 토큰 치환(값 동일). `--ggc-text-body` 정의 제거(토큰으로 승격) | 채택한 서비스만 재복사 |
| 줄끝 | `.gitattributes` 로 **LF 고정**. Windows 에서 clone 해도 LF 로 내려온다 | Windows 사본이 CRLF 였다면 재복사 후 D1 이 다시 성립한다 |
| 검사기 | 서비스 루트 하드코딩 제거(`GGC_SERVICES` / `--all <경로>`), D6 에 프로필 검사 추가 | CI 명령에 `--all` 인자 확인 |
| 문서 | `docs/23-…계약.md` → `docs/contract.md`, 스킬 `skills/2ggc-design` → `skills/ggc-design` | 링크·문서 참조 갱신 |

**색은 하나도 바뀌지 않았다.** 리팩터 전후 갤러리 6쪽 × 2폭(1440·390)의 전 요소 계산
스타일 해시가 일치한다(2026-08-29 실측). 재복사만 하면 화면이 달라질 일이 없다.

## 절차

```bash
# 1. 재복사 (손으로 옮겨 적지 않는다)
cp <저장소>/design/ggc-tokens.css      <서비스>/<정적루트>/ggc-tokens.css
cp <저장소>/design/ggc-components.css  <서비스>/<정적루트>/ggc-components.css   # 채택한 경우만

# 2. 검사 — D1 이 "정본과 바이트 동일" 이어야 한다
python <저장소>/design/check_design.py --gate <서비스경로>
```

## 신설 토큰 (기본값 = 현행 실측값)

| 이름 | 무엇 | 기본(업무) | 대민 프로필 |
|---|---|---|---|
| `--ggc-space-8` ~ `-11` | 간격 확장 (KRDS gap 다음 스텝) | 40 / 48 / 64 / 80 | 동일 |
| `--ggc-text-body` | 카드 안 긴 본문 단락색 (승격) | 값은 토큰 파일 | 동일 |
| `--ggc-control-h-sm` / `-h` / `-h-lg` | 버튼 높이 sm / 기본 / lg | 34 / 42 / 46 | 40 / 48 / 56 |
| `--ggc-input-h` | 입력·셀렉트 높이 | 44 | 48 |
| `--ggc-search-h` | 검색창 높이 | 40 | 48 |
| `--ggc-control-font` / `-sm` / `-lg` | 버튼·입력 글자 | 13.5 / 13 / 14 | 17 / 15 / 19 |
| `--ggc-label-font` | 폼 라벨 글자 | 13 | 17 |
| `--ggc-table-font` | 표 글자 | 13 | 17 |
| `--ggc-cell-pad` | 표 th·td 패딩 | 11px 10px | 12px 16px |
| `--ggc-row-pad` | 행 리스트 패딩 | 15px 22px | 20px 24px |
| `--ggc-card-pad` | 자유 본문 카드 패딩 | 18px 22px | 24px 24px |
| `--ggc-container-max` | 유틸리티 바·푸터 inner 폭 | 1280 | 1248 |

값 단위는 px. 표는 색인이며 정본은 `design/ggc-tokens.css` 다 — 갈리면 파일이 옳다.

## 인라인형(❸)·독자형(❹) 서비스

값이 바뀌지 않았으므로 **할 일이 없다.** 자기 CSS 의 하드코딩 hex 는 v1.2 와 같은 값이다.
다만 대민 프로필을 쓰려면 토큰 파일을 도입(❷ 사본형 전환)해야 한다 — 프로필 블록이
토큰 파일 안에 있기 때문이다.

## 대민 프로필을 켜는 법

```html
<html lang="ko" data-ggc-profile="public">
```

이것뿐이다. 버튼·입력·표·행 리스트·카드 패딩·컨테이너 폭이 KRDS 치수로 바뀌고,
색·포커스·서체는 그대로다. 대민 셸(masthead·identifier·공개 헤더/푸터)은
`design/ggc-public.css` (Phase 4) 가 담당한다.
