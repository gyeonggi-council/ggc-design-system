# v3.2 → v4.0 — 잉크 강조 · 깊이 세 단계 · 새 중립 램프 · 부품 셋

⚠ **D1** — 정본 파일의 바이트가 바뀌었다: `ggc-tokens.css` · `ggc-components.css` · `ggc-public.css`. 사본을 **재복사**한다.
`ggc-behaviors.js` · `ggc-fonts.css` · `ggc-icons.svg` 는 그대로다. 결정: [ADR 0016](../decisions/0016-astryx-look-ink-accent.md).
**일괄로 옮기지 않는다** — 그 서비스의 화면을 다음에 고칠 때 옮기고, 옮긴 날 화면을 열어 확인한다(ADR 0012-7).

## 먼저 — 내 서비스의 사본이 어느 판인가

```bash
python tools/ggc.py check <서비스경로>                 # D1 줄에 「사본 vX · 정본 v4.0」
python tools/ggc.py upgrade <서비스경로>               # 미리보기 — 최신 / 공식 옛 판 / 현지 수정본
python tools/ggc.py upgrade <서비스경로> --apply       # 공식 옛 판만 바꾼다 · 옛 사본은 ~/.cache/ggc-canon-backup/ 에
```

## 서비스가 할 일

1. 재복사(위 명령). 이름은 늘기만 했으므로 옛 마크업은 그대로 렌더된다.
2. 서비스 CSS 에서 **주 버튼 · 선택 · 체크를 `--ggc-primary` 로 덧칠한 줄**을 찾아 지운다 — 남색 주 버튼이 남아 있으면 그것이다.
   ```bash
   grep -n "ggc-primary" <서비스>/app.css        # 링크 · 브랜드가 아닌 자리에 남아 있으면 --ggc-accent 로
   ```
3. `box-shadow` 리터럴을 서비스가 직접 적었다면 `--ggc-shadow-low/-med/-high` 로 바꾼다. 카드에 그림자를 덧붙였다면 지운다(이제 기본이다).
4. Tier 2: `npx shadcn add @ggc/ggc-style -y` 로 테마 매핑을 다시 받는다. 소스 블록(qr-login · stepper · shell · file-upload · side-nav · listbox · public-header · prose · card)을 쓰면 그것도 다시 받는다.
5. 화면을 열어 1440 · 390 캡처. 주 버튼이 **하나**만 검게 보이는지 — 둘 이상이면 덜어내기 판정([less.md](../guides/less.md)).
