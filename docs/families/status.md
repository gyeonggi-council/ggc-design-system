# 패밀리 — 상태 보이기 부품

**권위: current.** 형제: `.ggc-badge` · `.ggc-tag` · `.ggc-alert` · `.ggc-toast` · `.ggc-progress` · `.ggc-job` · `.ggc-empty` · `.ggc-spinner` · `.ggc-skeleton`. **언제 무엇을 보이나**는 [guides/states.md](../guides/states.md)(상태 사전 포함)가 정하고, 이 기록은 형제들이 함께 지키는 꼴을 정한다.

## 함께 지키는 것

| 계약 | 판정법 |
|---|---|
| **색 단독 금지** — 모든 상태는 글자(또는 아이콘 + 글자)로 읽힌다. 배지의 색은 보조다 | 색을 빼도(고대비 · 흑백 인쇄) 상태를 알 수 있다. `forced-colors` 에서 테두리 보장(§36) |
| **상태색은 넷**(`--ggc-success` `--ggc-warning` `--ggc-danger` `--ggc-info`)과 중립. 새 상태색을 만들지 않는다(ADR 0001) | D2 |
| **상태 사전의 말을 쓴다** — 「승인」 「반려」 「처리 중」 … 서비스마다 다른 말을 만들지 않는다 | states.md 「상태 사전」에 없는 말이면 사전을 먼저 늘린다 |
| **기다림은 시간으로 가른다** — 1초 미만 아무것도 · ~3초 `.ggc-spinner`/`.ggc-skeleton` · 3초 넘으면 `.ggc-job`(경과 시간 · 단계 · 오래 걸림 안내) | 긴 작업에 스피너만 도는 화면 없음 |
| **진행 막대는 센 값이 있을 때만** — 모르는 길이는 막대가 아니라 경과 시간 | `.ggc-progress` 에 `aria-valuenow` 가 있다 |
| **빈 화면은 조립** — `.ggc-empty` 는 자리만 잡고, 안에 **왜 비었나 + 다음 행동**(단추)을 넣는다(ADR 0006). 오류 · 검색 결과 없음 · 처음 · 권한 없음을 가른다 | 「데이터가 없습니다」 한 줄짜리 빈 화면 0건 |
| **저장 · 제출 결과는 화면에 남긴다** — 토스트는 짧은 확인에만 | 업무 근거가 되는 결과는 `.ggc-alert` 또는 본문 |
| **오류는 사유 + 해결** — 코드 · 스택 · 「오류가 발생했습니다」 단독 금지. 덜어내기의 예외 대상(계약 §11) | 오류 문장에 사용자가 할 수 있는 일이 있다 |
| **같은 상태는 한 번** — 제목 · 배지 · 띠 · 오른쪽 칸에 되풀이하지 않는다([less.md](../guides/less.md) R2) | 한 화면에 같은 상태 표시 ≤ 1 (고른 문서 확인용은 예외) |

## 선택 기준 — 어느 형제가 맡나

| 무엇을 말하나 | 형제 |
|---|---|
| 항목(행 · 문서)의 처리 상태 · 회기 판정 · 역할 | `.ggc-badge` (`--approved` `--pending` `--rejected` `--session` … `--role-*`) |
| 분류 · 출처 · 조건(상태가 아닌 것) | `.ggc-tag` |
| 화면 · 구역 수준의 안내 · 결과 · 긴급 띠 | `.ggc-alert` (`--banner` 는 화면 맨 위 하나) |
| 짧은 확인(복사됨 · 임시저장됨) | `.ggc-toast` |
| 센 값이 있는 진행(3/10쪽 · 42%) | `.ggc-progress` |
| 3초 넘는 시스템 작업(변환 · 추출 · 발송) | `.ggc-job` (상태 8종 · 경과 시간 · 오래 걸림) |
| 짧은 로딩 | `.ggc-spinner` (단추 안 · 블록) · `.ggc-skeleton` (목록 · 카드 자리) |
| 비어 있음(네 가지 이유) | `.ggc-empty` + 조립 |
