# 패밀리 — 뜨는 층 (오버레이)

**권위: current.** 형제: `.ggc-modal`(`<dialog>` · `--sm` `--lg` `--alert` `--full`) · `.ggc-menu`(`<details>`) · `.ggc-tooltip` · `.ggc-toast` · 「전체메뉴」 서랍(업무 LNB 서랍 · 대민 `.ggc-main-menu`). 동작은 `design/ggc-behaviors.js` 가 준다.

## 함께 지키는 것

| 계약 | 판정법 |
|---|---|
| **깊이는 세 단계** — 카드·KPI 는 `--ggc-shadow-low`, 이 패밀리의 메뉴·토스트·팝오버는 `-med`, 모달은 `-high`(v4.0, ADR 0016). 단추는 그림자 없음. 그림자는 경계를 돕지 주 신호가 아니다 | 리터럴 `box-shadow` 없음 — 전부 토큰. `forced-colors` 에서는 테두리가 경계를 지킨다 |
| **한 번에 하나** — 모달 위에 모달을 열지 않는다. 메뉴가 열린 채 모달이 뜨면 메뉴는 닫힌다 | 갤러리에서 두 층이 겹치는 상태가 없다 |
| **포커스를 가두고 돌려준다** — 열리면 첫 초점 요소(닫기 단추 또는 첫 입력)로, 닫히면 **연 요소**로 | 키보드로 열고 Tab 을 돌려도 뒤 문서로 새지 않는다. 닫은 뒤 초점이 보인다 |
| **Esc 로 닫힌다.** 바깥 클릭은 모달(`--alert` 제외) · 메뉴 · 서랍에서 닫힌다. 툴팁은 Esc 와 초점 이탈로 사라진다 | 갤러리 각 부품의 「키보드 · ARIA」 |
| **뒤 문서는 고정** — `--full` 모달과 서랍이 열린 동안 본문이 스크롤되지 않고, 서랍은 `inert` | 휴대폰에서 서명 중 화면이 흔들리지 않는다(v3.2 재발 방지) |
| **색만으로 종류를 말하지 않는다** — 토스트 · 알림 모달은 아이콘(lucide) + 문장 | 아이콘 없는 `--danger` 없음 |
| **토스트는 기본 알림 수단이 아니다** — 저절로 사라지고 시야 밖에 뜬다. 제출 · 결재 결과는 화면에 남긴다([states.md](../guides/states.md)) | 토스트로만 알리는 업무 결과 0건 |
| **휴대폰(≤600)** — 모달은 바닥에서 올라오거나 전체 화면, 서랍은 오른쪽(ADR 0014), 메뉴는 화면 안에 들어온다 | 390 에서 잘림 · 가로 스크롤 0 |

## 선택 기준

| 상황 | 형제 |
|---|---|
| 하던 일을 멈추고 확인 · 입력받기 | `.ggc-modal` (`--alert` 는 파괴적 확인, `--full` 은 서명 · 문서 크게 보기) |
| 셋 이상의 부차 동작 | `.ggc-menu` (둘 이하면 단추로 꺼내 둔다) |
| 아이콘 단추의 이름 · 짧은 풀이 | `.ggc-tooltip` (내용이 필수 정보면 툴팁이 아니라 본문) |
| 짧은 확인(복사됨 · 임시저장됨) | `.ggc-toast` |
| 좁은 화면의 내비게이션 | 「전체메뉴」 서랍 — 업무 · 대민이 같은 자리 · 같은 말 |
