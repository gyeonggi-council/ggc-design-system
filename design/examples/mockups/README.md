# 서비스 목업 — 정본으로 그린 새 서비스 시안

새 서비스를 기획할 때 **정본 CSS 만으로 화면이 어떻게 나오는지** 먼저 보여 주는 시안이다.
정본(토큰 · 컴포넌트)이 아니고, 서비스 코드도 아니다. 화면의 이름 · 일시 · 연락처는 모두 예시 데이터다.

브라우저로 바로 연다(서버 불필요). 휴대폰 폭은 개발자 도구의 기기 보기(390px)로 본다.

| 파일 | 화면 | 프로필 · 틀 |
|---|---|---|
| [`meeting-week.html`](meeting-week.html) | 회의 일정 관리 ① 주간 일정 — 확인할 일 + 주간 일정표 | 업무 · 풀셸 |
| [`meeting-detail.html`](meeting-detail.html) | ② 회의 상세 — 회의 정보 · 안건 · 회의자료 · 통지 열람 · 처리 이력 | 업무 · Learn/Decide |
| [`meeting-create.html`](meeting-create.html) | ③ 회의 등록 — 한 화면 입력 + 하단 액션바(임시저장 · 결재 상신) | 업무 · Configure(단계 막대 없음) |
| [`meeting-mobile.html`](meeting-mobile.html) | ④ 의원용 내 회의 일정 — 날짜별 목록 · 회의자료 · 참석 회신 | 업무 · 풀셸(≤900 전체메뉴 서랍) |
| [`ecard.html`](ecard.html) | **전자명함** — QR 을 찍은 상대방이 보는 화면 · 연락처 저장 | 대민 · `.ggc-solo` |

## 이 폴더의 규칙 — 갤러리와 같다

- 정본을 **상대경로로 직접 링크**한다(`../../ggc-tokens.css` …). 사본을 두지 않는다.
- 목업 전용 배치는 `meeting.css` · `ecard.css` 에만 둔다. 색 · 치수 리터럴 없이 `--ggc-*` 토큰만 참조한다. **서비스에 복사하지 않는다.**
- 아이콘은 lucide 스프라이트를 `python design/build-icons.py` 가 넣는다(`ggc-icons:begin` 표지 사이 — 손으로 고치지 않는다).
- 검사는 갤러리와 함께 돈다 — `bash tools/check-all.sh` 의 「갤러리 · 업무」가 이 폴더까지 본다.
- 목업이 서비스가 되면 그 서비스 저장소에서 스킬(`skills/ggc-design/SKILL.md`) 절차대로 정본을 **복사**해 다시 조립한다. 이 폴더의 HTML 을 그대로 옮겨 쓰지 않는다.

## 회의 일정 관리

| 화면 | 누가 · 무엇을 하러 오나 |
|---|---|
| 주간 일정 | 사무처 담당자(입법조사관 · 의사담당) — 한 주 회의를 훑고, 회의실 겹침 · 통지 전 · 자료 대기를 처리한다 |
| 회의 상세 | 담당자 · 위원장 — 회의 한 건의 안건 · 자료 · 통지 열람을 확인하고 일정을 바꾼다 |
| 회의 등록 | 담당자 — 회의를 계획하고 위원장 결재로 넘긴다. 결재 뒤 개회 통지 · 출석 요구 · 누리집 공고가 이어진다 |
| 내 회의 일정 | 의원 — 휴대폰에서 내 회의와 회의자료를 보고 간담회 참석을 회신한다 |

**판정** (덜어내기 · 상태 보이기)

- 처리할 것은 일정표에서 눈으로 찾게 하지 않고 「확인할 일」 한 곳에 모은다. 건수 KPI 는 두지 않는다 — 다음 행동을 바꾸지 않는다.
- 회의 종류는 배경색과 「본회의 · 위원회 · 간담회」 글자로 함께 가른다. 겹침은 테두리 + 「겹침」 글자, 연기는 점선 + 취소선 + 「연기」.
- 회의 상태(통지 완료 · 통지 전 · 자료 대기)는 배지 하나다. 단계 막대를 두지 않는다 — 사용자가 단계를 오가는 입력이 아니다.
- 등록은 한 화면에 끝나는 입력이라 단계 막대 없이 하단 액션바만 둔다. 사용 중인 회의실은 사유를 적고 고를 수 없게 한다.
- 회의자료는 **출처(의정자료 전자유통시스템)와 동기화 시각**을 남긴다 — 덜어낼 대상이 아니다.

**아직 없는 것** — 월간 · 목록 보기, 회의실 현황, 빈 화면 · 오류 · 로딩 상태, 회의록 연계.
회기 번호 · 통지 기한(「개회 2일 전」)은 예시 값이다 — 서비스를 만들 때 「경기도의회 회의규칙」 등 근거 규정에 맞춘다.

## 전자명함 — 받는 사람 화면

**누가 · 무엇을 하러 오나** — 종이 명함이나 화면의 QR 을 휴대폰 카메라로 찍은 **상대방**(도민 · 기관 담당자 · 업체)이,
로그인이나 앱 설치 없이 ① 누구인지 확인하고 ② 바로 전화 · 메일 · 지도를 열고 ③ 연락처에 저장한다.

**틀** — 정본 `.ggc-solo`(휴대폰 1인 링크 화면, [docs/components/solo.md](../../../docs/components/solo.md)).
대민 프로필(`data-ggc-profile="public"`)이되 대민 셸(마스트헤드 · 공개 푸터)은 생략한다 — 링크 하나로 한 가지 일을 하러 온 화면이라 셸이 그 일을 밀어낸다(계약 §9 예외와 같은 근거).

| 자리 | 무엇 | 왜 |
|---|---|---|
| 명함 | 의회 마크 · 기관명 · 부서 · **이름(h1)** · 직급 · 맡은 업무 한 줄 · 「경기도의회가 발급한 명함입니다」 | 받은 사람이 가장 먼저 확인하는 것은 "누구이고 진짜인가"다 |
| 연락처 | 줄 하나가 곧 단추 — 사무실 · 휴대전화 · 이메일 · 팩스 · 주소(지도) · 누리집 | 손가락으로 누르기 좋게 줄마다 큰 단추 높이. 팩스는 누를 일이 없어 단추가 아니다 |
| 맡은 일 | `.ggc-text-list` 셋 이내 | "이 일은 이 사람에게 물으면 되는가"를 가른다 |
| 바닥 띠 | 주 단추 **「연락처에 저장」**(vCard 내려받기) + 상태 칸 | 다음 할 일은 하나다. 저장 결과는 토스트가 아니라 상태 칸에 |
| 보내기 | 「명함 보내기」(휴대폰 공유) · 「주소 복사」 | 받은 명함을 동료에게 넘긴다 |

**상태** — `?state=` 로 바꿔 본다.

| 상태 | 보이는 것 |
|---|---|
| `card` | 명함 (기본) |
| `loading` | 「명함을 불러오고 있습니다」 |
| `gone` | 「이 명함을 열 수 없습니다」 — 다시 찍기 · 대표전화 |
| `moved` | 「지금은 쓰지 않는 명함입니다」 — **옛 연락처는 보이지 않고** 지금 연락할 곳만 알린다(인사이동 · 퇴직) |

### 1,000장을 운영하려면

- **쪽은 하나, 자료는 사람마다.** 이 HTML 한 장이 틀이고, 사람마다 다른 것은 자료(이름 · 부서 · 연락처 · 맡은 일)뿐이다.
- **QR 주소는 바꾸지 않는다.** QR 은 종이에 인쇄되므로 되돌릴 수 없다. 주소는 `…/card#<토큰>` 처럼 고정하고, 내용은 서버가 그때그때 답한다.
  인사이동이 나면 같은 QR 이 새 소속을 보여 주거나 `moved` 상태가 된다. 토큰은 `#` 뒤에 둔다(서버 로그 · Referer 에 남지 않는다 — solo.md).
- **개인정보** — 휴대전화는 본인이 공개를 고른 경우만 보인다. 링크 미리보기(OG) 문구에 이름을 넣지 않는다. `noindex` · `no-referrer`.
- **저장 내용 = 화면 내용** — vCard 는 화면에 그려진 값에서 만든다. 화면과 저장 내용이 갈라질 자리가 없다.

### 실기기에서 확인할 것

헤드리스 브라우저로 확인할 수 없다 — 사람이 본다.

- 아이폰 · 갤럭시 기본 카메라로 QR 을 찍으면 바로 열리는가
- 카카오톡 · 네이버 앱 안 브라우저에서 「연락처에 저장」 파일이 내려받아지고 연락처 앱으로 넘어가는가(인앱 브라우저는 내려받기를 막는 경우가 있다 — 그때 「기본 브라우저로 열기」 안내가 필요한지)
- 저장한 연락처에 부서 · 직급 · 주소가 한글 그대로 들어가는가

### 다음 단계로 둔 것

- **받았는지 확인** — 개인을 식별하지 않는 열람 수 집계(명함별 · 일자별)가 먼저다. 받은 사람이 자기 연락처를 남기는 「내 명함 보내기」는 개인정보 수집 동의가 필요하므로 따로 판단한다.
- **발급 관리 화면**(업무 프로필) — 1,000명 일괄 발급 · 인사 자료 연계 · 공개 항목 본인 선택 · 인쇄용 QR 내려받기.
- **진위 확인** — 지금은 「경기도의회가 발급한 명함입니다」 문구다. 모바일 블록체인 서비스와 이으면 발급 기록 대조로 바꿀 수 있다.
