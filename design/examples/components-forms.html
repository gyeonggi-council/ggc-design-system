폼 컨트롤

ggc-components.css v3.0 · §16~17 · §24 · §27~28 · §32

셀렉트 · 체크박스 · 라디오 · 칩 · 토글 스위치 · 날짜 · 파일 업로드 · 리스트박스. 리스트박스만 빼고 전부 네이티브 input 위에 CSS 만 얹은 것이라 키보드·스크린리더·폼 전송이 브라우저 그대로 동작한다. 이미지 자산이 없다 — 화살표와 체크 표시는 CSS 가 그린다. 마크업 구조와 ARIA 는 KRDS 컴포넌트를 따랐다.

대민 프로필에서는 이 컨트롤들이 KRDS 치수(48px · 17px)로 커진다. <html data-ggc-profile="public"> 한 줄이며, 마크업은 같다. 토큰 페이지의 토글로 확인할 수 있다.

셀렉트 .ggc-select

네이티브 <select> 를 .ggc-select 로 감싸면 화살표가 붙고 높이가 --ggc-input-h 를 따른다. .ggc-field 안에서는 감싸기만 하면 라벨·힌트·오류가 그대로 붙는다. 커스텀 리스트박스(검색·다중 선택)는 별도 컴포넌트(P2)다 — 항목이 20개 이하면 네이티브가 낫다.

토글 스위치 .ggc-switch

날짜 입력 .ggc-date · .ggc-date-range

        
네이티브 <input type="date"> 다 — 달력 · 키보드(화살표로 년/월/일) · 스크린리더를
          브라우저가 준다. min/max 로 회기 범위를 잠근다. 힌트에 서버 형식(YYYY-MM-DD)을 적는다 —
          브라우저 표시 형식과 다르다. 커스텀 달력(범위 하이라이트 · 회기 표시)은 예정 항목이다.

파일 업로드 .ggc-file · .ggc-file-list

        
선택 버튼 + 끌어놓기 영역 + 선택한 파일 목록(KRDS file_upload). input 은 시각적으로만 숨겨 Tab 으로
          도달하고 Enter 로 열린다. 목록과 삭제는 ggc-behaviors.js 가 채우고
          삭제를 input.files 에 되돌린다 — 폼 전송이 목록과 같다. 허용 형식 · 크기 · 개수를 미리 적는다.
