경기도의회 공통 디자인 시스템

토큰 v3.0 · 컴포넌트 v3.0 · Tier 2 레지스트리 v3

의정정보시스템 11개 프런트엔드가 공유하는 한 벌이다. Next 14/15/16 · React 18/19 · Vite · JSP/Tiles · Jinja2 · FastAPI · 정적 HTML — 스택이 일곱 종이라 공유 단위를 CSS 커스텀 프로퍼티까지 낮췄다. 패키지가 아니라 복사다.

지금 보고 있는 이 페이지가 예제다. 별도 스타일시트를 갖지 않고 ../ggc-tokens.css 와 ../ggc-components.css 를 상대경로로 직접 링크한다. 상단 유틸리티 바 · GNB 64px · LNB 256px · 본문 1320px 은 전부 계약 §2 의 공통 셸이고, 여기서 손으로 그린 것이 없다.

정본이 바뀌면 이 페이지가 같이 바뀐다. 갤러리가 정본을 배신할 수 없다는 뜻이고, 반대로 정본이 깨지면 여기가 눈에 띄게 망가진다.

무엇부터 보나

01 · TOKENS 토큰 · 팔레트 색 · 타이포 · 간격 · 형태 · 포커스 전수. 값과 대비비는 브라우저가 정본에서 실측해 채운다 — 옮겨 적은 숫자가 한 개도 없다. 02 · COMPONENTS 컴포넌트 카탈로그 버튼 · 배지 · 카드 · 통계 · 행리스트 · 표 · 폼 · 위저드. 각 예제 아래에 렌더된 그 마크업이 그대로 펼쳐진다. 03 · MONITOR 대시보드 화면 Archetype 이 실제 업무 화면으로 조립되면 어떻게 되는지. 통계 4종 · 결재 흐름 · 심사 현황표 · 회기 일정. 04 · CONFIGURE 위저드 화면 조례 초안 작성 4단계. 스텝퍼 3형(가로·세로·미니) · 폼 필드 · 오류/힌트 · 빈 상태 3종. 05 · ENTRY QR 로그인 화면 전 시스템 공통 입구. 상태 6종 · 화면 안 3단계 안내 · 사용자 코드 · 바꾸면 안 되는 계약.

3분 도입

빌드 도구도 패키지 매니저도 필요 없다. 파일 두 개를 복사하고 자기 스타일보다 먼저 로드한다. 순서가 곧 우선순위다.

1  복사   design/ggc-tokens.css      →  <서비스>/<정적루트>/ggc-tokens.css
           design/ggc-components.css  →  <서비스>/<정적루트>/ggc-components.css
           design/brand/dist/*        →  ASSET-MAP.tsv 가 지정한 경로

2  로드   <link rel="stylesheet" href="ggc-tokens.css">      ← 반드시 먼저
           <link rel="stylesheet" href="ggc-components.css">
           <link rel="stylesheet" href="app.css">              ← 자기 스타일

3  검사   python design/check_design.py --gate <서비스경로>

손으로 옮겨 적지 않는다. D1 검사가 사본의 바이트 동일을 요구한다. 한 글자만 달라도 FAIL 이고, 그것이 이 시스템의 유일한 강제 수단이다.

값을 인라인으로 이식하는 것도 막지 않는다 — 다만 D2 검사가 소스의 모든 색 리터럴을 정본에서 파생한 허용집합과 대조한다. 발명한 색은 그 자리에서 잡힌다.

관통 원칙 — 이름은 복제해도 되고, 값은 복제하면 안 된다

이 조직에서 값 복제는 이미 실패한 실험이다. 계약 문서가 선언한 --ggc-success 값이 실물 CSS 와 두 달간 어긋난 채 아무도 그 갭을 보지 않았다.

복제해도 되는 것
토큰 이름
--ggc-primary 는 소비자와의 인터페이스다. 문서·스킬·이 갤러리가 색인해도 안전하다.
복제하면 안 되는 것
토큰 값
#3c5d93 는 구현이다. design/ggc-tokens.css 한 곳에만 산다. 문서에 적는 순간 그 줄은 낡기 시작한다.

그래서 이 갤러리에는 손으로 적은 색값이 하나도 없다. 토큰 페이지의 스와치와 대비비는 getComputedStyle 로 정본을 읽어 채우고, 컴포넌트 페이지의 코드블록은 렌더된 데모의 실제 innerHTML 을 읽어 채운다.

접근성 — 값보다 먼저 지키는 것

경기도의회는 공공기관이라 KWCAG 2.2 가 법적 준수 대상이다. 토큰 v1.2 는 자기 자신이 AA(4.5:1)를 통과한다 — v1.1 은 통과하지 못했고, 상태 배지 7종이 전부 미달이었다.

키보드
지금 Tab 을 눌러 보라. 맨 처음 나오는 것이 본문 바로가기 링크이고, 이후 모든 컨트롤에 포커스 링이 보인다. 디자인 원본은 outline:none 을 28곳에 두고 대체를 두지 않았다 — 그 지점만은 원본을 따르지 않았다.
고대비
Windows 고대비 테마를 켜고 다시 보라. 팔레트를 하나 더 만들지 않고 forced-colors 에서 깨지지 않게 했다. 이 모드에서 box-shadow 가 렌더되지 않아 포커스 링이 통째로 사라지던 결함을 outline 으로 복원했다.
색 단독 의존 금지
상태 배지에는 항상 텍스트나 아이콘을 함께 둔다. 색각 이상 사용자에게는 대비만으로 부족하다. --ggc-text-faint 는 이름과 달리 텍스트용이 아니다 — 아이콘 stroke·구분선 전용이다.

이 갤러리를 여는 법

서버도 빌드도 필요 없다. 저장소를 내려받아 design/examples/index.html 을 브라우저로 열면 된다. GitHub 웹에서는 HTML 이 렌더되지 않고 소스로만 보인다.

글꼴은 폴백으로 보일 수 있다. 이 저장소는 Pretendard GOV 파일을 담지 않는다(자체 호스팅 대상이고, 외부 CDN 은 망분리 환경에서 깨지므로 링크하지 않는다). 폰트가 없으면 토큰의 폴백 체인이 동작해 Windows 에서는 맑은 고딕으로 떨어진다 — 자간·굵기만 다르고 레이아웃은 같다.
