### 본청 파비콘을 쓰지 않는 이유

경기도의회 홈페이지의 실제 파비콘은 `/design/theme/asa/images/g_favicon.ico` 로,
**`assembly_mark.png` 와는 다른 별도 파일**이다. 그것을 받아오려면 외부 접근이 필요한데
망분리 환경에서 재현이 불가능하다. 따라서 우리는 **이미 저장소 안에 있는 마크에서
파비콘을 파생**한다. 본청 파비콘과 픽셀 단위로 같지 않다 — 의도된 결과다.

## 생성물 (`dist/`)

| 파일 | 무엇 | 어디에 |
|---|---|---|
| `favicon.ico` | 16+32+48, **BMP 페이로드**, 32bpp | **`ggc-poc-web` 한 곳만** |
| `favicon-32.png` | 32×32 불투명 | 전 서비스 |
| `apple-touch-icon-180.png` | 180×180 불투명 | 전 서비스 |
| `assembly-mark.png` | 원본 바이트 그대로 | GNB 40×40 용 |
| `MANIFEST.sha256` | 무결성 | 게이트가 읽는다 |

### 왜 이 다섯뿐인가

- **`.ico` 는 오리진당 하나면 된다.** 모든 서비스가 `27.96.x.x` 한 오리진 아래
  경로 프리픽스(`/kb`·`/hr`·`/award`…)로 살고, **브라우저의 암묵적 `/favicon.ico`
  요청은 항상 오리진 루트로 간다.** 그 루트를 점유한 것이 `ggc-poc-web` 이다.
  하위 경로 서비스에 `.ico` 를 둬도 선언 없이는 영영 요청되지 않는다.
- **`favicon.svg` — 만들지 않는다.** 이 마크는 금색 화환 + 진홍 메달리언의 세밀한
  3색 래스터다. SVG 로 다시 그리는 것은 **마크를 다시 디자인하는 일**이다.
- **`favicon-16.png` — 만들지 않는다.** Chrome 이 32 를 잘 줄이고, 16 은 `.ico` 안에 있다.
- **`manifest.webmanifest` — 만들지 않는다.** PWA 계획이 없고, 더 결정적으로
  `_template`·`ggc_kb` 의 세션 게이트 공개 정규식
  `^/[\w.-]+\.(?:css|js|ico|png|svg|woff2?)$` 에 `.webmanifest` 가 **매칭되지 않아
  로그인 화면에서 401** 이 난다. 넣으려면 "빠뜨리면 파드가 무한 재시작한다" 는 주석이
  달린 인증 미들웨어를 건드려야 한다. 같은 함정이 `bill-system/rhwp/` 벤더 번들에서
  이미 실현돼 있다 — 아이콘 5개 전부 404, 스코프가 배포 프리픽스를 반영하지 못해 무효.
- **`mask-icon` — 만들지 않는다.** Safari 15(2021) 이후 사실상 죽은 선언이다.

### ICO 를 BMP 페이로드로 쓰는 이유

저장소에 두 전례가 공존한다 — `ggc_ai_hipass` 는 PNG 페이로드, `award_office` 는 BMP.
브라우저는 둘 다 읽지만 **Windows 셸(작업표시줄 고정·바로가기)은 256 미만 PNG
페이로드를 공식 지원하지 않는다.** BMP 로 쓰면 양쪽에서 옳다.

원본 270×268 을 리샘플 없이 ICO 로 감싸는 방법은 **성립하지 않는다** —
`ICONDIRENTRY.bWidth`/`bHeight` 가 각 1바이트이고 `0` 이 256 을 뜻해 **270 은 표현
불가**다. (PNG 로 감싸는 판은 `bill-system` 에서 이미 돌고 있지만, 16px 탭 하나
그리려고 35,581 바이트를 받고 비정사각이라 종횡비가 깨진다.)

## 재현

```bash
cd /d/260712_경기도의회_시스템구축/design/brand
python build-brand-assets.py          # dist/ 재생성
python build-brand-assets.py --check  # MANIFEST 대조만
```

의존성 0 — Python 표준 라이브러리(`zlib`·`struct`)만 쓴다. 이 PC 에는 Pillow 도
ImageMagick 도 없다. (`/c/WINDOWS/system32/convert` 는 Windows 디스크 변환 유틸이다.
**절대 실행하지 말 것.**)

**생성 결과물이 정본이다. 게이트는 정본↔사본만 비교하고 이 스크립트를 재실행하지
않는다** — `zlib.compress` 출력은 파이썬·zlib 버전에 따라 달라질 수 있다.
스크립트는 재현·감사용이다.

## 배포

경로 규약과 서비스별 대상은 `ASSET-MAP.tsv` 가 정본이다. 게이트는 그 표를 읽어
행마다 `diff` 를 돌린다 — Next App Router 가 파일명을 `icon.png`/`apple-icon.png` 로
강제하므로 **이름 통일은 애초에 불가능**하고, 따라서 이름이 아니라 **표로 매핑을 고정**한다.
표에 없는 서비스는 "미적용" 으로 명시적으로 드러난다. 지금처럼 조용히 빠지지 않는다.
