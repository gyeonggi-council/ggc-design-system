# Surface Archetype — 화면을 무엇으로 어떤 순서로 채우는가

계약 §4 가 6종을 정의한다. 원본은 화면이 7개다. **1:1 이 아니고, 그 불일치가 이 문서의 핵심이다.**

| Archetype | 원본 뷰 | `.dc.html` | 상태 |
|---|---|---|---|
| Monitor | `view_dashboard` | `대시보드.dc.html` | 정본 있음 |
| Explore | `view_repair` | `필수조례정비 지원.dc.html` | 정본 있음 |
| Learn/Decide | `view_report` + `view_budget` | `입법검토보고서` · `예산분석 비용추계` | **2화면 → 본문 슬롯 2변형** |
| Configure | `view_wizard` | `조례초안 작성 위저드.dc.html` | 정본 있음 |
| Converse | `view_monitor` | `입법 모니터링 정책챗.dc.html` | 정본 있음 |
| **Operate** | **없음** | 없음 | 🔴 **정본 부재** |

- **Learn/Decide 를 둘로 쪼개지 않는다.** 골격 앞뒤(제목·메타 / 결재·감사)가 같고 **본문
  슬롯만 다르다.** 공통 골격 + `--doc`(문서형) / `--figure`(수치형)로 처방한다.
  계약 §4 의 6종을 7종으로 늘리지 않는다.
- **Operate 는 정본에 화면이 없다.** 아래 처방은 Monitor 골격 + 계약 §5 의 실시간자막 요구
  (세션·실시간 편집·상태/오류/복구·회의록)에서 **파생한 신규 디자인 결정**이다.
  "정본대로 구현" 이 아니므로, 첫 구현 서비스가 실제 화면으로 확정한 뒤 **이 문서를 갱신한다.**

**판정은 성격이나 목적이 아니라 구성요소로 한다.** 목적으로 가르면 사람마다 갈린다.

---

## Monitor

**판정** — KPI 타일 행이 있고 테이블이 없다. 서비스 진입 첫 화면. 배타: 스티키 액션바가 있으면 Configure 다.
**격자** — `.ggc-shell-main` (1320px). 하단 `1fr 320px` 2열, `align-items: start`.

| # | 슬롯 | 컴포넌트 | 개수 | 비고 |
|---|---|---|---|---|
| 1 | 맥락 헤더 | GNB 제목부 | 1 | **아래 "헤더 제목부 2형" 참조** |
| 2 | 주 액션 | `.ggc-btn--primary` + secondary | 1~2 | 우측 정렬 |
| 3 | KPI 행 | `.ggc-stat-grid` | **정확히 4** | `repeat(4,1fr)`, 900px 이하 2열 |
| 4 | 업무 큐 | `.ggc-card` + `.ggc-list-row` | 1 | 진행 단계 표시 포함 |
| 5 | 결재·상태 흐름 | `.ggc-card` | 1 | |
| 6 | 최근 항목 / AI 작업 큐 | `.ggc-card` (우측 레일) | 1~2 | [선택] |

**세 상태** — 빈: KPI 는 0 으로 렌더하고 큐 자리에 "처리할 항목이 없습니다" + 시작 액션.
오류: 카드 단위로 격리(한 카드 실패가 화면 전체를 죽이지 않는다). 로딩: 스켈레톤 아닌 타일 자리 유지.

**하지 말 것** — KPI 를 5개 이상 넣기(격자가 `repeat(4,1fr)` 고정이다) · 대시보드에 테이블 넣기
(그건 Explore 다) · `--ggc-main-max-wide` 쓰기(대시보드만 1320 이다).

### 헤더 제목부 2형

원본 마스터의 최신 수정이 이 지점이다 — breadcrumb 을 **맥락형 인사말**로 교체했다.

- **Monitor 에서만**: `{이름}님, 오늘 처리할 {업무} {N}건이 있습니다` (17px/800/-0.03em)
  + 부제 한 줄 (11.5px, `--ggc-text-faint` 는 텍스트라 쓰지 않는다 → `--ggc-text-subtle`)
- **나머지 화면**: `홈 / {상위}` breadcrumb + 페이지 제목 (18px/800/-0.02em)

## Explore

**판정** — 검색·필터 스트립 + 목록/표 + 상태 칩. 배타: 단일 레코드 상세면 Learn/Decide 다.
**격자** — `.ggc-shell-main--wide` (1360px). 단일 컬럼.

| # | 슬롯 | 컴포넌트 | 개수 | 비고 |
|---|---|---|---|---|
| 1 | breadcrumb 헤더 | | 1 | |
| 2 | 필터 스트립 | `.ggc-card` 안 칩·셀렉트 | 1 | 검색은 `.ggc-search` (300×40) |
| 3 | 결과 요약 | 텍스트 | 1 | "총 N건" |
| 4 | 목록 | `.ggc-card` + `.ggc-table` 또는 `.ggc-list-row` | 1 | |
| 5 | 행 좌측 심각도 바 | `5px` 폭 `--ggc-radius-sm`, 행 높이 전체 | 행당 1 | [선택] 등급이 있을 때만 |
| 6 | 페이지네이션 | | 1 | |

표는 `font-variant-numeric: tabular-nums`, 행 구분 `--ggc-hairline`, 행 hover `--ggc-row-hover`.

**세 상태** — 빈: 필터 때문인지 데이터가 없는 건지 **구분해서** 문구를 다르게 한다
(가장 자주 빠지는 곳이다). 오류: 표 자리에 재시도 버튼. 로딩: 행 높이 유지.

**하지 말 것** — 상태를 색으로만 표시하기(`.ggc-badge` 에 텍스트 병기) ·
페이지네이션 없이 전량 렌더 · 390px 에서 표가 가로 오버플로하게 두기(래퍼에 `overflow-x`).

## Learn / Decide

**판정** — 단일 레코드의 상세 + 결재/검토 흐름. 본문이 문서면 `--doc`, 수치면 `--figure`.
**격자** — `.ggc-shell-main--wide` (1360px). `1fr 320px` 2열(우측은 결재·이력 레일).

| # | 슬롯 | 컴포넌트 | 개수 | 비고 |
|---|---|---|---|---|
| 1 | 제목 · 메타 | `.ggc-card--pad` | 1 | 작성자 실명·역할·부서. **UUID 금지**(계약 §2) |
| 2a | 본문 `--doc` | `.ggc-card` + `.ggc-prose` | 1 | 조문·단락. 확폭 시 측정 폭 920px 캡 |
| 2b | 본문 `--figure` | `.ggc-table` + 막대 시각화 + 요인 분해 | 1 | 합계행 `border-top: 2px solid var(--ggc-primary-deep)` + `--ggc-surface-inset` |
| 3 | 근거·출처 | `.ggc-tag` 목록 | 1 | AI 산출이면 **필수** |
| 4 | 결재선 | `.ggc-card` (우측 레일) | 1 | 단계별 상태 도트 |
| 5 | 의견·코멘트 | `.ggc-card` | 1 | [선택] |
| 6 | 감사 이력 | `.ggc-card` | 1 | |

**세 상태** — 빈: 결재선이 비면 "상신 전" 을 명시. 오류: 본문 로드 실패와 결재 로드 실패를 분리.
로딩: 제목·메타를 먼저 그리고 본문만 지연.

**하지 말 것** — 주 액션을 두 개 이상 두기(무엇을 눌러야 하는지 흐려진다) ·
숫자에 `tabular-nums` 빼먹기(자릿수가 흔들린다) · 근거 없이 AI 산출값만 보여주기.

## Configure

**판정** — 단계 표시(스텝퍼) + **하단 스티키 액션바**. **액션바가 없으면 Configure 가 아니다.**
**격자** — `.ggc-shell-main--wide`. 하단 패딩을 크게(액션바가 가린다 — 원본은 120px).

| # | 슬롯 | 컴포넌트 | 개수 | 비고 |
|---|---|---|---|---|
| 1 | 스텝퍼 | `.ggc-wizard` | 1 | 완료=success · 현재=primary + `--ggc-focus-ring` · 대기=중립 |
| 2 | 단계 본문 폼 | `.ggc-field` | 단계당 1블록 | |
| 3 | 검증 피드백 | 인라인 메시지 | 필드당 0~1 | 색 단독 금지 — 아이콘·문구 병기 |
| 4 | 보조 패널 | `.ggc-card` | [선택] | 도움말·미리보기 |
| 5 | **스티키 액션바** | 하단 고정 | 1 | `rgba(255,255,255,.92)` + `backdrop-filter: blur(8px)` + `0 -4px 16px` |
| 6 | 임시저장 / 상신 | `.ggc-btn--secondary` + `--primary` | 2 | 순서 고정 |

**세 상태** — 빈: 1단계 진입 시 무엇을 입력해야 하는지 예시. 오류: 검증 실패한 **첫 필드로
포커스를 옮긴다**(키보드 사용자에게 필수). 로딩: 상신 중 액션바 버튼 비활성 + 진행 표시.

**하지 말 것** — 단계 이동으로 입력을 잃게 하기(임시저장이 왜 있는지) ·
스텝퍼를 장식으로만 쓰기(현재 단계가 어디인지 색과 형태 **둘 다**로) ·
액션바를 `position: fixed` 없이 문서 흐름에 두기.

## Converse

**판정** — 대화 스트림 + 출처/근거 패널. **유일하게 격자가 다르다.**
**격자** — `.ggc-shell-main--split` — `minmax(320px,1fr) minmax(340px,420px)`,
`height: calc(100vh - var(--ggc-gnb-h))`, `max-width` 없음. 900px 이하에서 1열로 접힌다.

| # | 슬롯 | 컴포넌트 | 개수 | 비고 |
|---|---|---|---|---|
| 1 | 대화 스트림 | `.ggc-scroll` 컨테이너 | 1 | 사용자/AI 말풍선 비대칭. AI 쪽 `border-radius: 14px 14px 14px 4px` |
| 2 | 출처 인용 패널 | 우측 레일 `.ggc-card` | 1 | **AI 답변에 출처가 있으면 필수** |
| 3 | 입력부 | 하단 고정 textarea + 액션 | 1 | Enter 전송 / Shift+Enter 줄바꿈을 **명시** |
| 4 | 스트리밍 표시 | | 1 | `prefers-reduced-motion` 존중 |
| 5 | 오류·재시도 | 인라인 | 1 | 일일 한도 429 를 사용자 언어로 |

**세 상태** — 빈: 첫 진입에 **예시 질문 3~4개**를 칩으로(빈 대화창은 무엇을 물어야 할지 모른다).
오류: 스트림 안에 인라인으로 + 재시도 버튼. 로딩: 타이핑 인디케이터.

**하지 말 것** — 출처 없이 AI 답변만 보여주기 · 스트리밍 중 입력 잠그지 않기 ·
`overflow` 를 페이지에 두기(스크롤은 대화 컨테이너 안에서만).

## Operate 🔴 정본 부재

> ⚠ **아래는 정본이 아니라 파생 설계다.** 계열 N 원본에 Operate 화면이 없다.
> Monitor 골격 + 계약 §5 의 실시간자막 요구에서 파생했다.
> **첫 구현 서비스가 실제 화면으로 확정한 뒤 이 절을 갱신할 것.**

**판정** — 실시간 상태 + 명령·복구 액션 + 로그.
**격자** — `.ggc-shell-main--wide`. 상단 상태 스트립 + `1fr 380px`.

| # | 슬롯 | 컴포넌트 | 개수 | 비고 |
|---|---|---|---|---|
| 1 | 실시간 상태 스트립 | 상태 도트 + 라벨 | 1 | 도트 7~8px + `0 0 0 3px` 틴트 후광 (원본 실측 패턴 재사용) |
| 2 | 세션·작업 목록 | `.ggc-list-row` | 1 | |
| 3 | 로그 페인 | `--ggc-font-mono` + `.ggc-scroll` | 1 | 자동 스크롤 토글 |
| 4 | 명령·복구 액션 | `.ggc-btn` | 1블록 | **파괴적 동작은 확인 단계** |
| 5 | 권한 상태 | `.ggc-badge` | 1 | 지금 무엇을 할 수 있는지 |

**세 상태** — 빈: "실행 중인 세션 없음" + 시작 액션. 오류: 연결 끊김을 **상태 스트립에서**
먼저 알린다. 로딩: 마지막으로 알려진 상태를 흐리게 유지(빈 화면으로 깜빡이지 않는다).

**하지 말 것** — 상태를 색으로만 표시 · 로그를 무한 누적(가상 스크롤 또는 상한) ·
복구 액션을 주 액션과 같은 무게로 두기.

## 공통 — 모든 archetype

- **빈 상태·오류·로딩 3종을 함께 만든다.** `/1ggc-deploy` Phase 1 문항 4("데이터가 0건일 때
  무엇이 보이나")의 답이 여기서 화면이 된다.
- **사용자 표기는 실명·역할·부서다. UUID 금지**(계약 §2).
- **카드는 그림자가 없다**(계약 §2). radius 14~16px.
- **역할 배지는 상태 배지와 다른 축**이다 — `.ggc-badge--role-*` 를 쓴다.
- 슬롯 명세의 수치는 컴포넌트 CSS 가 갖고 있다. **여기서 값을 다시 적지 않는다** —
  더 자세한 것이 필요하면 `.dc.html` 원본을 직접 연다.
