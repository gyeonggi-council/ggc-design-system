# 샘플 목업 — 디자인 결정

$ROOT: 이 저장소(`mockups/sample/` 의 두 단계 위)

## work.html
프로필: work
- 착지: Tier 1 CSS 복사(정적 HTML) · 형 ❷ 사본형(정본과 바이트 동일)
- 셸: ⓑ 풀셸(GNB + LNB) · 유틸리티 바 마크업은 두고 기본 숨김
- 패턴: Explore — 필터 스트립 · 결과 요약 한 곳(「총 12건 · 처리 중 7건」) · 표 · 쪽
- 표 열: 정본 목록 표의 열 순서(번호 · 제목 · …)를 따르고, 상태 말이 네 글자라 `app.css` 에서 상태 · 의원 열을 넓혔다
- 세 상태: 빈 상태(필터 때문인 경우의 문구)는 마크업에 숨겨 두었다

## work-detail.html
프로필: work · 패턴: Learn/Decide — 머리(제목 · 상태 · 기한) · 일부 회신 경고 · 요구 내용 · 회신 자료 · AI 대조(출처 함께) · 처리 이력 · 메모
- 외부 발송(독촉)은 확인 창에서 받는 곳과 보낼 문장을 미리 보여 준다 — 덜어내기 대상이 아니다
- 처리 이력은 상태 배지 대신 왼쪽 띠만 쓴다(같은 상태를 두 번 말하지 않는다)

## work-form.html
프로필: work · 패턴: Configure — 3단계(요구 내용 → 대상 기관 · 기한 → 확인 · 전달), 단계 막대는 단계를 오가는 입력이라 둔다
- 오류는 입력 바로 아래, 고칠 방법과 함께(「기간과 항목을 적어 주세요 — 예: …」)
- AI 안내는 중복 요구를 알릴 때만 나타나고 출처(기존 요구)를 단다

- 패턴: 메인 — 히어로 검색 · 회기 알림 띠 · 진행 중인 도민참여 · 이번 주 회의 일정 · 새 소식

## public-detail.html

## public-form.html
프로필: public · 패턴: 서식 — 3단계 막대 · 회의 선택(남은 자리 · 마감 · 마감된 회의는 고를 수 없음) · 신청자 정보 · 개인정보 동의 · 입장 안내
- 설명 줄 없음 — 마감 · 남은 자리 · 입장 방법처럼 판단에 필요한 안내만 그 자리에

## caption-dashboard.html
프로필: work · 패턴: Monitor — 끊김 알림(있을 때만) · 통계 셋(방송 중 · 평균 지연 · 확인 필요) · 회의별 상태 표 · 용어 확인 · 남은 일정

## caption-live.html
프로필: work · 패턴: Operate 실시간 시청 — 한 줄 머리(회의 · 방송 중 · 감사 순서 단추 · 자막 검색 · 집중모드) · 영상 · 탭(자막 · 검색결과 · 요구자료) · 자막 목록 · 지금 발언 · 연결 상태(끊길 때만)
- 화면에 딱 맞는 앱이라 공통 푸터를 생략했다(종일 띄우는 화면 — 아키타입 처방). 메뉴와 브레드크럼은 남긴다
- 읽던 사람을 최신 위치로 끌고 가지 않는다 — 맨 아래를 볼 때만 따라가고, 아니면 「새 자막 n · 최신으로」
- 영상 위에 자막 · 시계 · 화자를 겹치지 않는다 · 화자 이름을 붙이지 않는다(근거 없는 화자 이름 금지)
- 지금 발언 배경은 v4.0 규칙대로 남색이 아니라 중립 강조(`--ggc-accent-muted`)

## caption-focus.html
프로필: work · 패턴: Operate 집중모드 — 셸 없이 얇은 머리 한 줄(회의 · 방송 중 · 지금 안건 · 글자 크기 · 전체 화면 · 끝내기) + 영상 + 자막
- 글자 크기 세 단계는 토큰 글자 스텝(`--ggc-text-*`)만 고른다 · 전체 화면은 브라우저 기능(Esc 로 빠진다)
- 1100px 아래에서는 영상 아래 자막으로 쌓는다(휴대폰은 일반 시청 화면이 같은 배치)

## 공통
- AA: observe · 확폭: 집중모드만 1920×1080 확인 · 예외 색: 없음
- 문서 여백: 정본은 `body` 여백을 건드리지 않는다 — 목업 `app.css` 가 0 으로 둔다(화면 맞춤 높이가 8px 씩 어긋났다)
- 덜어내기: 설명 줄 없음(대민 히어로 안내문 한 줄만) · 건수는 결과 요약 한 곳 · 상태는 배지 하나에 글자 병기 · 단계 막대 없음
- 휴대폰 확인(2026-11-08, Chromium · iPhone 13 에뮬레이션 · PC 1440, 여섯 쪽 합본): 가로 넘침 0 · 콘솔 오류 0 · 외부 요청 0 · 폰트 적용 · 쪽 사이 링크 끊김 0 · 독촉 확인 창 → 토스트 · 탭 전환 동작
- 실시간 자막 확인(같은 날): 시청 · 집중모드 페이지 세로 스크롤 0(390 · 1440 · 1920) · 자막 추가 흉내 · 위로 읽는 중 강제 이동 없음 · 글자 크기 단계 동작
