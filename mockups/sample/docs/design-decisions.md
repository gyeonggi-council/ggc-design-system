# 샘플 목업 — 디자인 결정

$ROOT: 이 저장소(`mockups/sample/` 의 두 단계 위)

## work.html
프로필: work
- 착지: Tier 1 CSS 복사(정적 HTML) · 형 ❷ 사본형(정본과 바이트 동일)
- 셸: ⓑ 풀셸(GNB + LNB) · 유틸리티 바 마크업은 두고 기본 숨김
- 패턴: Explore — 필터 스트립 · 결과 요약 한 곳(「총 12건 · 처리 중 7건」) · 표 · 쪽
- 표 열: 정본 목록 표의 열 순서(번호 · 제목 · …)를 따르고, 상태 말이 네 글자라 `app.css` 에서 상태 · 의원 열을 넓혔다
- 세 상태: 빈 상태(필터 때문인 경우의 문구)는 마크업에 숨겨 두었다

## work-detail.html
프로필: work · 패턴: Learn/Decide — 머리(제목 · 상태 · 기한) · 일부 회신 경고 · 요구 내용 · 회신 자료 · AI 대조(출처 함께) · 처리 이력 · 메모
- 외부 발송(독촉)은 확인 창에서 받는 곳과 보낼 문장을 미리 보여 준다 — 덜어내기 대상이 아니다
- 처리 이력은 상태 배지 대신 왼쪽 띠만 쓴다(같은 상태를 두 번 말하지 않는다)

## work-form.html
프로필: work · 패턴: Configure — 3단계(요구 내용 → 대상 기관 · 기한 → 확인 · 전달), 단계 막대는 단계를 오가는 입력이라 둔다
- 오류는 입력 바로 아래, 고칠 방법과 함께(「기간과 항목을 적어 주세요 — 예: …」)
- AI 안내는 중복 요구를 알릴 때만 나타나고 출처(기존 요구)를 단다

## public.html
프로필: public
- 셸: 마스트헤드 → 헤더 · 주 메뉴 → 공개 푸터 → 아이덴티파이어(문구 무변경)
- 패턴: 메인 — 히어로 검색 · 회기 알림 띠 · 진행 중인 도민참여 · 이번 주 회의 일정 · 새 소식

## public-detail.html
프로필: public · 패턴: 상세 — 사이드 내비 · 제목 · 기본 정보 표 · 탭(내용 · 경과 · 첨부) · 의견 접수 안내 · 목록/인쇄

## public-form.html
프로필: public · 패턴: 서식 — 3단계 막대 · 회의 선택(남은 자리 · 마감 · 마감된 회의는 고를 수 없음) · 신청자 정보 · 개인정보 동의 · 입장 안내
- 설명 줄 없음 — 마감 · 남은 자리 · 입장 방법처럼 판단에 필요한 안내만 그 자리에
